# ParsingFIxLIP
Project for Explainable AI course at University of Warsaw. Extending FIxLIP by grouping tokens semantically with Tree gram parsing. Evaluation new method on BiomedCLiP.

## Our work:
[paper.pdf](paper.pdf)

# Abstract
Vision-Language Models (VLMs) in the medical domain require explanations that align
with precise clinical terminology. We introduce an extension to standard [FIxLIP (NeurIPS 2025)](https://arxiv.org/abs/2508.05430) attribution, incorporating linguistic dependency parsing trees to define players in the Banzhaf
interaction game. By grouping tokens we address the raw tokens problem and provide
semantically coherent cross-modal explanations of BiomedCLIP on the radiology dataset.
